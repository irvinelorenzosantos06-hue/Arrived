# NexUS Command Center

A real-time **Autonomous AI & Cloud Orchestration Platform** built with **Next.js 16 (App Router)**, **TypeScript**, and **Vanilla Glassmorphic CSS**.

---

## ⚡ Features

- **Autonomous Agent Fleet Manager**: Monitor compute load, RAM allocations, latency SLAs, foundation models, and active tasks across agents like Atlas Prime, Krypton Semantic, and Sentinel Aegis. Pause, resume, and inspect live memory buffers.
- **Visual Workflow Orchestrator**: Multi-stage sequential consensus pipeline (Ingress Trigger &rarr; Semantic Context &rarr; Multi-Agent Swarm &rarr; Guardrail Consensus &rarr; Dispatch) with real-time animated execution simulation.
- **Neural Playground Terminal**: Interactive execution console to dispatch directives, inspect synthesized reasoning steps, trace tool calls, and view streaming token analytics.
- **Live Mesh Telemetry Feed**: Real-time streaming log console with severity filtering (`ACTION`, `INFO`, `SUCCESS`, `WARN`, `ERROR`), text search, and JSON export.
- **Agent Deployment Engine**: Provision new autonomous agents with customizable foundation models (Gemini 2.5 Ultra, Claude 3.7 Sonnet, DeepSeek R1, GPT-4.5 Orion), autonomy clearance levels, and hardware tool entitlements.
- **Glassmorphic Cyberpunk Theme**: Dark mode design system with SVG sparkline metrics, glowing neon accents, and responsive layout.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the dashboard.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript 5
- **Styling**: Vanilla CSS Modules (Glassmorphism, CSS Custom Properties, Google Fonts *Plus Jakarta Sans* & *JetBrains Mono*)
- **Icons**: Lucide React
